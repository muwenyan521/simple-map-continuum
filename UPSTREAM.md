# Upstream and Maintenance

This repository is an independent rewrite derived from the behavior and data
formats of [Simple Map](https://github.com/muwenyan521/Simple-Map). The legacy
fork remains available as a reference archive; this repository is the active
development target.

The original license and copyright notices remain in [LICENSE](LICENSE). The
rewrite does not claim to be endorsed by the upstream project or its author.
Compatibility changes are documented in commits and in the versioned archive
codecs under `core`.
